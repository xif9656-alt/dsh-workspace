# 回归测试用例

用于修改Skill后做行为验证，不能只检查关键词是否存在。将输入交给加载Skill的独立会话，记录实际输出、漏项和执行日期；以下预期是评估依据，不应在独立首轮一并提供。

## 输入
审查室内素拓方案：30人分6队、6站，每轮10分钟（8分钟游戏＋2分钟复位）。S08为T+10至T+20，S09为T+20换站2分钟，S10仍从T+20开始。总窗口180分钟，高情景分段60＋10＋60＋25＋15＋10，声称合计180。最低工作人员4人，岗位另列物资1人、站长6人且可由参赛队员担任。物资T−50到岗，S02全体布置T−50至T−30，主持T−30到岗。安全巡检T−30开始15分钟，验收却要求T−30前完成。玩法需要绳子、便签、垃圾袋，预算未列来源。纸牌塔按名次递减，跳站折算未写公式。蒙眼移动标为“无高危”，自行写1米安全半径。场地、安全联系人、必要审批均待办，开头写“定稿，填入即用”。只有文档自述框架已确认，无对话记录。

## 判定要点
应发现：交接重复/时间重叠；高情景仅170分钟（缺分配10分钟，不等同超时）；岗位峰值与4人冲突；参赛站长冲突；布置到岗和验收前置冲突；漏列物资来源成本；计分不可操作；无依据安全参数；执行状态不成立；框架确认只能视为材料自述。应保留正确的每轮8＋2结构，不能机械增加两次换站。最多3问，不得凭文档认定审批通过。

## 修订后复核
要求给出一版局部修订，核对站点/时间/SOP/岗位/预算/风险/验收状态同步更新，不能仅修改汇总表。不得将缺失价格编成真实报价或将人工核实标为已完成。
