# 多活动策划模板

## 1. 模式与范围
模式：候选筛选 / 多个独立活动 / 系列活动（可混合，注明阶段）。
本轮范围：[ ]；用户要求数量[ ]；已选ID[ ]；未选项不是执行承诺。
公共约束：目标[ ]、参与对象[ ]、人手[ ]、总资金[ ]、窗口[ ]，每项注明来源、状态和适用活动。

## 2. 候选对比（筛选阶段）
|ID/名称|玩法与目标|人数/人手|时长含准备撤场|成本估算及前提|场地/风险/限制|推荐理由|选择状态|
|---|---|---|---|---|---|---|---|
不得用无依据的安全参数或“零风险”包装候选。推荐不能代替选择和框架确认。

## 3. 活动总览（选定后）
|ID/名称|独立/系列归属|负责人|T或日期窗口|方案/框架版本及确认范围|预算上限/估算/落实资金|审批与安全状态|阻断项/责任人/期限|文件位置|
|---|---|---|---|---|---|---|---|---|
每场记录单独的事实与假设表。用户一次明确确认多个框架时记录具体ID和版本；只确认A不得标B已确认。
建议文件组织：00-活动总览.md；A01-活动名/审批策划案.md、现场执行手册.md、验证附件.md。少量简短活动可放一个文档，以ID分节。

## 4. 共用资源与冲突
|资源/人员|可用数量及依据|涉及活动ID|占用起止含布撤场/运输/复位|并行需求/峰值|缺口或未知|调整方案/影响活动|确认人/节点|
|---|---|---|---|---|---|---|---|
时间未定：分别使用T_A01、T_A02，列出若重叠则需满足的条件，不能因相对时间相同就认定同日冲突，也不能宣称无冲突。日期落实后统一换算检查。
人员按同时在岗任务核对，设备按可复用数量及转运检查；活动延期、取消或设备损坏后重算后续场次。

## 5. 总预算与系列计划
总估算=共享一次性成本+各场增量成本+适用租赁周期费用+周转损耗+按明确基数计算的备用金；共用资产只计采购一次，每场耗材逐场计算。现金占用含押金和报销时滞，押金占用与最终支出分列。
|成本ID|共享/场次归属|数量/单价/依据|总费用|各场分摊（如需）|支付时点/落实资金|未报价项|
|---|---|---|---|---|---|---|
系列另列：场次→目标→前置依赖→产出→下一场交接→备选日期。参与人数区分人次与去重人数，不把每场人数相加冒称独立受益人数。

## 6. 验收
逐场检查审批案、手册与验证附件一致；逐场给出文档状态及执行放行建议。总览不得将未核实场次自动标通过。共享资源变更记录受影响ID、修订位置、复查证据及未关闭事项。
