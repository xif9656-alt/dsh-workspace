# 审查与最终验收清单

逐项标记：通过 / 不通过 / 待核实 / 不适用（说明原因）。

- 目标是否可衡量，活动形式能否支持目标？对象和参与路径是否清楚？
- 框架是否获人工确认，确认版本与执行版本是否一致？
- 已知、假设和未知是否分开，数据是否有来源？
- T时间轴是否含准备、轮换、复位、缓冲和撤场，是否符合借用窗口？
- 人数、队伍、并行工位、吞吐量、岗位和预算计算是否一致？
- 每个分区是否有容量、人流、设施需求及现场核实安排？
- SOP是否有责任、前置条件、完成证据、异常处理和交接？是否有同人同时多岗冲突？
- 物资是否列数量、单价、借购、到位期限、备用和归还责任？
- 风险是否有触发、停止、应急、恢复条件和授权人？安全数值是否有可靠适用依据？
- 审批、专业核实、紧急联系、天气与备用方案是否落实？
- 宣传承诺、规则、评分申诉、隐私与无障碍是否按需覆盖？
- 多模型审查是否真实执行，版本与原始意见是否保留？
- 待确认、审批和整改是否指定责任人、期限与阻断影响？
- 活动前/中/后验收是否有指标、证据、验收人和资产财务闭环？

|---|---|---|---|---|---|---|
等级：阻断（安全/必要审批/关键资源缺失）、重大（不能按计划完成）、一般（表达或局部效率）。不得仅给分不列证据，不以多数投票关闭阻断项。

## 验收结论
- 可执行：必要审批、关键资源、安全核实均有有效证据，阻断项清零；说明适用版本及现场条件。
- 有条件通过：仅剩非阻断事项，列责任人和完成节点；不等于允许未审批环节开展。
- 暂不可执行：有阻断项，列解除所需证据与替代方案。
文档完整性与现场放行分别判断。AI只能提供文档审查建议；现场放行由有权限的人员决定。未实测的数据标记估算；未完成的核实不得勾选通过。

## 交叉复算操作表
|检查|必须出示的证据|常见错误|
|---|---|---|
|时间|每情景起止、持续、依赖、并行理由、总占用；与SOP逐段对照|10分钟已含2分钟交接，又另加2分钟；高情景总和170却写180|
|缓冲|明确空档的起止、用途及被占用后的调整|未分配10分钟不一定超时，但不能宣称已分配完整；并行检查不能把工时当历时|
|岗位|按关键时间段列岗位×人员矩阵，统计同时在岗人数，核对到离岗及替补|布置写全体但工作人员晚到；安全巡检未开始就要求验收完成；物资岗离岗早于撤场|
|轮转|每队每轮所在站点表、每站容量、站长来源和评分独立性|参赛队员同时担任固定站长；只有4人却另要求6站同时有人值守|
|预算|玩法/SOP物资→数量→借购来源→费用逐项对照；保留未报价项|绳、便签、垃圾袋、备用耗材漏列；免费借用未确认；固定项与人均项重算|
|计分|每站满分、名次递减、并列、未完成、取消站点、折算及申诉规则|只写按名次递减；临时跳站后未规定全队统一分母；人数不同造成优势|
|安全|逐玩法检查移动、视线遮挡、加载、卫生和退出选择，参数依据与现场核实人|把蒙眼活动称为无风险；用无依据的1米半径作安全标准|
|状态|确认来源、阻断项及解除凭据，区分文档就绪与现场放行|只有方案自称已确认；场地审批待办却声称可执行|

发现问题时先定位原文，再复算并记录结论；修正涉及站点数、时长或岗位后，回查所有关联表格。保留合理假设，不把未提供的信息直接判为已证实错误。

## 执行可操作性补查
- 每个动作是否能在人员、物资、场地和记录工具清单找到资源？
- 所有降级方案是否独立复算，岗位替补是否保留原职责覆盖？
- 评分是否说明并列、签名来源、候场得分、长度测量及组织方取消站点的公平处理？
- AI是否逐步推演并记录实际发现，真人试玩是否有真实证据，未执行是否如实注明？
- 是否给工作人员精简现场手册，且与审批策划案同版本？
- 问题和选项是否通俗、必要、尊重隐私，不重复追问已有答案？

## 多活动附加检查（适用时）
- 是否识别候选筛选、独立活动或系列活动，未把未选候选直接当执行任务？
- 每轮追问是否全局不超过3项，各活动确认、审批和事实是否独立？
- 是否检查共享人手、场地、物资周转和资金；时间未知是否保留冲突检查条件？
- 总预算是否避免共享采购重复计费，系列人数是否区分人次与去重人数？
- 总览、各场审批案及手册是否同版本，个别阻断是否仍可见？

## 最终文件证据
- 已修复项能否在最终正文找到实际修改，附件与手册是否一致？
- 校验是否覆盖同轮同队重复占站、岗位任务冲突和真实候场人数，而非只计次数与非空格？
- 是否区分算术、约束、正文与现场四层验证，使用数值模型时是否完成有意义的输入变化检查？
