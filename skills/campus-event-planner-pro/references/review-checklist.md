# 审查与最终验收清单

逐项标记：通过 / 不通过 / 待核实 / 不适用（说明原因）。

- 目标是否可衡量，活动形式能否支持目标？对象和参与路径是否清楚？
- 框架是否获人工确认，确认版本与执行版本是否一致？
- 已知、假设和未知是否分开，数据是否有来源？工作假设是否已转正或降级并写明未转正后果？
- T时间轴是否含准备、轮换、复位、缓冲和撤场，是否符合借用窗口？
- **时长是否回算闭合**：布置+签到准备+串行环节+轮数×每轮周期+收尾+缓冲，是否等于用户确认的总时长？修改时间轴后，岗位到岗时刻、借用窗口、风险表时间条件是否已同步（全文是否只有一套时间基准）？
- **轮转拓扑与容量是否成立**：串行换站需L≥K，并联工位需C×L≥K；是否写明用了哪种拓扑、是否混算？
- 人数、队伍、并行工位、吞吐量、岗位和预算计算是否一致？
- 每个分区是否有容量、人流、设施需求及现场核实安排？是否覆盖无障碍要求（通行宽度、台阶、替代参与方式）？
- SOP是否有责任、前置条件、完成证据、异常处理和交接？是否有同人同时多岗冲突？安全岗是否专职不兼？
- **争议与申诉口径**是否写明（受理人、截止时点、终裁人、过时是否受理、记录方式）？
- 物资是否列数量、单价、借购、到位期限、备用和归还责任？
- 风险是否有触发、停止、应急、恢复条件和授权人？安全数值是否有可靠适用依据？
- **高危项目**是否已识别（承压、弹射、明火、临电、高空、拥挤、信任背摔、毕业墙/电网、攀爬架、真人CS、涉水涉冰、夜间定向、气球爆破、剧烈追逐），且未形成"未满足前不开展"的阻断表述？
- 审批、专业核实、紧急联系、天气与备用方案是否落实？应急联络是否为占位待填而非编造？
- 宣传承诺、规则、评分申诉、隐私与无障碍是否按需覆盖？
- **独立审查状态**是否在交付文档中如实声明（执行/未执行、执行者、版本）；未执行是否提供了可复制指令，且未冒称多模型交叉验证？
- 模板要求的字段是否都已填（逐条比对规划模板的表格列，缺列即视为未覆盖，不得只写结论不列证据）？
- 待确认、审批和整改是否指定责任人、期限与阻断影响？
- 活动前/中/后验收是否有指标、证据、验收人和资产财务闭环？文档完整性与现场放行是否分开结论？

## 验收结论
- 可执行：必要审批、关键资源、安全核实均有有效证据，阻断项清零；说明适用版本及现场条件。
- 有条件通过：仅剩非阻断事项，列责任人和完成节点；不等于允许未审批环节开展。
- 暂不可执行：有阻断项，列解除所需证据与替代方案。
文档完整性与现场放行分别判断。AI只能提供文档审查建议；现场放行由有权限的人员决定。未实测的数据标记估算；未完成的核实不得勾选通过。
